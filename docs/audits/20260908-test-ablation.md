# 测试消融与回归验证

## 判据

测试减少分为两类：随功能删除而失效的测试，以及保留功能中重复或仅约束实现形式的测试。不能把参数化后测试函数变少当成行为覆盖减少，也不能用总数量推断覆盖率。

基线为 `be6a0add0652a1e8ea34f93852d74908c9e81497`。源码中共有 774 个测试声明；原有 Windows 可运行测试为 740 项。声明数量包含其他平台限定测试，与实际运行数量不同。

## 功能裁剪

初次盘点识别出 70 项与已删除 daemon、时间表、自动换号选择器及相关设置绑定的测试。最终源码共 727 个测试声明，比基线净减少 47 个（约 6.1%）；同期新增了真实回归测试，净减少数量不能全部归因于删除。

保留真实文件锁、令牌轮换、登录并发写入、凭据恢复、本地 HTTP 和授权边界测试。它们保护仍在使用的 CLI/TUI 行为。

## 保留功能的测试消融

移除了三个不检验运行行为的测试：标准库行尾替换的镜像断言、Wiki 固定标题及“Next steps”措辞断言、README 固定词条断言。对应减少的是文字/实现形式约束。

文档链接可达、版本一致性、安装校验和、构建来源证明与发布顺序检查继续保留。消融后的 `test_distribution_contract` 在 Windows 最终实际运行 32 项，全部通过；Linux 为 36 项，全部通过。

## 缺陷注入实验

在 `target/audit-dev` 隔离副本中注入以下三种缺陷，运行对应测试，再恢复文件、重新编译并复测。主工作树未注入缺陷，全部使用临时目录、假凭据或本地 HTTP 服务。

| 实验变体 | 检出测试 | 注入后 | 恢复后 |
|---|---|---|---|
| 跳过 refresh token 比较，允许旧请求覆盖并发登录 | `refresh_token_cas_does_not_overwrite_a_concurrent_relogin` | 失败，exit 101 | 通过，exit 0 |
| 启动结束仍回写同账号旧凭据 | `audit_same_account_restore_keeps_rotated_live_credentials` | 失败，exit 101 | 通过，exit 0 |
| unattended 刷新错误复用新鲜缓存 | `an_unattended_refresh_still_ignores_a_fresh_usage_cache` | 失败，exit 101 | 通过，exit 0 |

每个缺陷对应独立测试；三项变体同时存在于实验副本，但各自修改不同函数。实验副本包含已修复的账号和启动代码，其他模块仍以基线为主；此实验不等于最终工作树全量验收。

原始日志位于本机 `target/verification/mutation-*.txt` 和 `restored-*.txt`。这三项实验支持保留相关测试，不构成整个测试集的 mutation coverage。

## 真实预热收益边界

本次本地 HTTP 测试能证明请求选择、失败处理与凭据持久化；不能证明真实账号预热降低了首请求延迟或产生额度窗口收益。未调用用户真实账号进行付费或配额消耗实验。

## 最终运行结果

- Windows：560 个库测试和 140 个集成测试均有通过证据，共 700 项，比基线可运行数量净减少 40 项。库全量初次 559 通过、1 个旧模型 fixture 失败；补足主池模型后，受影响两项通过。集成中的手写 HTTP fixture 发生超时提前响应，改用已有 Axum 后启动 8 项通过，其余集成分别通过。未用重复全量运行掩盖这两次失败。
- Linux：全量 718 项通过（572 库 + 146 集成）。HTTP fixture 变更后只重跑受影响启动集成 9 项，全部通过。
- Windows/Linux Clippy 通过；格式检查通过。macOS 尚待 CI，Windows ARM64 本机缺少 clang，未宣称通过。
