# Security policy

## Versions

Include the exact version from `codex-switch --version` in your report. Security fixes are tracked separately for the latest stable release and the rolling `dev` prerelease. For older versions, tell us whether the issue also occurs in either current release.

## Report a vulnerability

[Report a vulnerability privately](https://github.com/xjoker/codex-switch/security/advisories/new) through GitHub. Include the affected version, operating system, expected behavior, and the minimum steps needed to reproduce the issue with synthetic data.

Use the private report for details about credential exposure, unsafe writes or imports, and installer or updater verification failures. Remove live tokens, auth files, API keys, account metadata, and proxy credentials from any material you submit.
